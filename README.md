# Ropes and Shackles

What a kinetic recovery (a snatch) puts through your snatch strap or kinetic rope and its shackles, which strap or rope suits your two vehicles, and what a safety lanyard, a tree protector and a bridle are each for. You set it up on an animated picture.

Every number comes from SECURETECH (South Africa) first, then other makers (Factor 55, Samson, Crosby, WARN, Bushranger), Australia's recovery strap standard where no South African source publishes anything, or plain physics, and the Sources page shows each one with the words it comes from. Where nobody publishes a figure, the page says so.

Plain HTML, CSS and JavaScript: open `index.html` in a browser. Nothing you enter leaves your browser.
